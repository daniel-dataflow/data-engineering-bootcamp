1. 개념 정의
Function Based View (FBV)

- 하나의 HTTP 요청을 하나의 함수로 처리
- 요청 흐름이 직관적이며 Python 기본 문법 그대로 사용


Class Based View (CBV)

- 요청을 클래스로 정의하고 HTTP 메서드를 메서드 단위로 분리
- Django가 제공하는 Generic View를 상속해 사용


2. 핵심 비교 요약

구분		FBV			CBV
--------------------------------------------------
코드 구조		단순, 절차적		객체지향
가독성		요청 흐름이 한눈에 보임	구조 이해 필요
재사용성		낮음			매우 높음
확장성		제한적			우수
러닝 커브		낮음			높음
실무 사용		단순 로직			CRUD / 표준 API



3. 실무 기준 선택 가이드
FBV를 선택하는 경우

	단순한 API
	비즈니스 로직이 복잡하고 분기 많음
	Django 초보자 팀
	빠른 디버깅 필요
	예: webhook, 단발성 API, 특수 처리

CBV를 선택하는 경우

	CRUD 중심 서비스
	관리자/백오피스
	API 패턴이 반복됨
	대규모 팀 / 표준화 중요
	예: 게시판, 사용자 관리, 어드민 기능
