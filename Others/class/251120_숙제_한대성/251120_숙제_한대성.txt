JavaScript 연산자 우선순위 완전 정리

1. 최우선 - 그룹화

    ( ) - 괄호 (가장 먼저 계산됨)

2. 멤버 접근 & 호출

    obj.property - 멤버 접근 (점 표기법)
    obj[property] - 멤버 접근 (대괄호 표기법)
    new 생성자() - 인수 있는 new
    func() - 함수 호출
    ?. - 옵셔널 체이닝

3. 증감 연산자 (후위)

    x++ - 후위 증가
    x-- - 후위 감소

4. 단항 연산자

    !x - 논리 NOT
    ~x - 비트 NOT
    +x - 단항 플러스
    -x - 단항 마이너스
    ++x - 전위 증가
    --x - 전위 감소
    typeof x - 타입 확인
    void x - undefined 반환
    delete x - 프로퍼티 삭제
    await x - async 대기

5. 거듭제곱

    ** - 거듭제곱 (2 ** 3 = 8)

6. 곱셈/나눗셈/나머지

    * - 곱셈
    / - 나눗셈
    % - 나머지

7. 덧셈/뺄셈

    + - 덧셈/문자열 연결
    - - 뺄셈

8. 비트 시프트

    << - 왼쪽 시프트
    >> - 오른쪽 시프트
    >>> - 부호 없는 오른쪽 시프트

9. 관계 연산자

    < - 미만
    <= - 이하
    > - 초과
    >= - 이상
    in - 프로퍼티 존재 확인
    instanceof - 인스턴스 확인

10. 동등 비교

    == - 동등 (타입 변환 O)
    != - 부등 (타입 변환 O)
    === - 일치 (타입 변환 X)
    !== - 불일치 (타입 변환 X)

11. 비트 AND

    & - 비트 AND

12. 비트 XOR

    ^ - 비트 XOR

13. 비트 OR

    | - 비트 OR

14. 논리 AND

    && - 논리 AND (단축 평가)

15. 논리 OR

    || - 논리 OR (단축 평가)

16. Nullish 병합

    ?? - null 또는 undefined일 때만 (nullish coalescing)

17. 조건 연산자 (삼항)

    ? : - 조건 연산자 (a ? b : c)

18. 할당 연산자

    = - 할당
    +=, -=, *=, /=, %=, **= - 산술 할당
    <<=, >>=, >>>= - 비트 시프트 할당
    &=, ^=, |= - 비트 연산 할당
    &&=, ||=, ??= - 논리 할당

19. yield (제너레이터)

    yield - 제너레이터 값 반환
    yield* - 제너레이터 위임

20. 쉼표

    , - 쉼표 (여러 표현식 평가, 마지막 값 반환)
