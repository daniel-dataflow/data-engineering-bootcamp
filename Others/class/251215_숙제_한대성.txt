1. 공개키 암호화(Public Key Cryptography)

1.1 개념
공개키 암호화는 **서로 다른 두 개의 키(key)**를 사용하는 암호화 방식입니다.
- 공개키(Public Key): 누구에게나 공개
- 개인키(Private Key): 소유자만 비밀로 보관
이 두 키는 수학적으로 연관되어 있으며, 한 키로 암호화한 데이터는 반대쪽 키로만 복호화할 수 있습니다.

1.2 동작 방식
수신자는 공개키와 개인키를 한 쌍으로 생성
수신자는 공개키를 외부에 공개키
송신자는 해당 공개키로 데이터를 암호화
수신자는 자신의 개인키로 복호화
핵심: 공개키로 암호화 → 개인키로만 복호화 가능

1.3 장점과 단점

장점
- 키 전달 문제 해결 (비밀키를 사전에 공유할 필요 없음)
- 안전한 통신 채널 구축 가능 (인터넷 환경에 적합)

단점
- 연산 비용이 큼 (속도가 느림)
- 대용량 데이터 암호화에는 비효율적
→ 실제 시스템에서는 **대칭키 암호화와 혼합(Hybrid 방식)**하여 사용

1.4 활용 예
- HTTPS (TLS/SSL)
- 전자서명
- 이메일 암호화 (PGP)
- 인증서 기반 인증

2. RSA 암호 알고리즘
2.1 RSA 개요
RSA는 공개키 암호화 알고리즘 중 가장 널리 사용되는 방식으로, 다음 세 사람의 이름에서 유래했습니다.
- Rivest
- Shamir
- Adleman
RSA의 보안성은 큰 소인수분해 문제의 계산적 어려움에 기반합니다.


2.2 RSA의 특징

장점
공개키 암호화의 대표 표준
전자서명과 암호화 모두 가능
수학적 구조가 명확

단점
매우 느림 (대칭키 대비)
키 길이가 길어야 안전 (보통 2048bit 이상)
양자컴퓨터 등장 시 취약 (Shor 알고리즘)
