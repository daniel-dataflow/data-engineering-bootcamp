1. 캐시 (Cache)
• 정의: 웹 페이지의 이미지, 비디오, 오디오, CSS, JS 파일 등 리소스 파일들을 임시로 저장해두는 곳입니다.
• 목적: 웹 페이지 로딩 속도를 높이고 서버 트래픽을 줄이기 위해 사용됩니다. (재사용성)
• 저장 위치: 클라이언트 (사용자 브라우저)

2. 쿠키 (Cookie)
• 정의: 사용자의 컴퓨터(브라우저)에 저장되는 작은 텍스트 파일입니다.
• 목적: 사용자 편의성 제공 (예: '다시 보지 않기' 팝업, 쇼핑몰 장바구니, 비로그인 상태 설정 유지).
• 저장 위치: 클라이언트 (사용자 브라우저)
• 보안: 상대적으로 취약함 (탈취 및 변조 위험).
• 수명: 만료 시간을 설정할 수 있으며, 브라우저를 닫아도 파일로 남아있을 수 있습니다.
• 속도: 빠름 (서버 요청 시 헤더에 담겨 전송됨).

3. 세션 (Session)
• 정의: 서버 측에서 사용자 정보를 관리하는 기술입니다.
• 목적: 보안이 중요한 정보 관리 (예: 로그인 상태 유지).
• 저장 위치: 서버 (메모리 또는 DB)
• 보안: 우수함 (중요 정보는 서버에 있고, 클라이언트는 세션 ID만 가짐).
• 수명: 브라우저를 종료하면 삭제됩니다.
• 속도: 쿠키보다 느림 (서버의 처리가 필요함).

4. 한 줄 요약
• 캐시: 리소스 로딩 속도 UP (이미지 등)
• 쿠키: 사용자 편의 정보 (클라이언트 저장, 보안 약함)
• 세션: 인증/중요 정보 (서버 저장, 보안 강함)
