1. ensure_ascii 속성 (한글 깨짐 방지)
기능: JSON 변환 시 ASCII 이외의 문자(한글, 이모지 등)를 유니코드 이스케이프 문자(`\uXXXX`)로 변환할지 여부 결정.

• `True` (기본값)

  • 모든 비 ASCII 문자를 `\u...` 형태로 변환.

  • 호환성은 좋으나 가독성이 떨어짐.

  • 예: `"한글"` -> `"\ud55c\uae00"`


• `False`

  • 문자를 변환하지 않고 그대로 출력.

  • 사람이 읽기 좋고, 일반적으로 UTF-8 환경에서 용량이 줄어듦.

  • 예: `"한글"` -> `"한글"`

2. json.dumps() vs json.dump() 차이
---

• json.dumps : 덤프 스 (String)
json.dumps = "말하기 (Talk)" (메모리 안에서만)
내가 가진 생각(데이터)을 말(문자열)로 내뱉습니다.
공기 중(메모리)에 존재하며, 받아적지 않으면 사라집니다.
Python 데이터를 **텍스트(글자)**로 바꿔서 변수에 저장하거나 화면에 찍을 때 씁니다.
"내 데이터를 JSON 형식의 '글자'로 바꿔줘!"

• json.dump : 그냥 덤프 (파일로 보냄)
json.dump = "편지 쓰기 (Write)"
내가 가진 생각(데이터)을 종이(파일)에 꾹꾹 눌러 씁니다.
책상 위(하드디스크)에 실물로 남습니다.
Python 데이터를 **진짜 파일(.json)**로 만들어서 컴퓨터에 저장할 때 씁니다.
"내 데이터를 JSON 파일에 '기록'해줘!"
