1. $pull : 값(Value) 또는 조건 기준 삭제
핵심 기능: 배열 안에서 특정 값이나 지정된 조건(query)과 일치하는 요소를 찾아 제거합니다.
삭제 범위: 조건에 맞는 요소가 여러 개라면 모두(All) 삭제합니다.
사용 목적: 데이터 클렌징, 특정 태그 제거, 필터링 등 내용물을 보고 지워야 할 때 사용합니다.

문법:
{ $pull: { 필드명: 삭제할_값_또는_조건 } }

2. $pop : 위치(Position) 기준 삭제
핵심 기능: 배열의 데이터 내용과 상관없이, **양 끝(맨 앞 또는 맨 뒤)**의 요소를 제거합니다.
삭제 범위: 한 번 실행 시 단 1개의 요소만 삭제합니다.
사용 목적: 스택(Stack), 큐(Queue) 자료구조 구현, 로그 데이터의 오래된 항목 삭제 등 순서가 중요할 때 사용합니다.

문법:
{ $pop: { 필드명: 1 } }  // 맨 뒤(Last) 요소 삭제
{ $pop: { 필드명: -1 } } // 맨 앞(First) 요소 삭제
