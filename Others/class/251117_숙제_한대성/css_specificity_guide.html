🧮 명시도 계산 방법

명시도는 (a, b, c) 형식으로 계산됩니다
a = ID 선택자 개수
b = 클래스 + 속성 + 가상 클래스 개수
c = 태그 + 가상 요소 개수
점수 환산: a×100 + b×10 + c×1

예시 1

p { color: black; }
계산: (0, 0, 1)
점수: 1점

예시 2

.intro { color: blue; }
계산: (0, 1, 0)
점수: 10점

예시 3

#header { color: red; }
계산: (1, 0, 0)
점수: 100점

예시 4

div.intro:hover { }
계산: (0, 2, 1)
점수: 21점

예시 5

#nav .menu li { }
계산: (1, 1, 1)
점수: 111점

예시 6

ul li:first-child { }
계산: (0, 1, 2)
점수: 12점

🎮 실전 대결 예시

다음 HTML에 여러 스타일이 적용되면 어떤 색이 될까요?
<p id="title" class="highlight">안녕하세요</p>
p { color: black; }
→ (0, 0, 1) = 1점 ❌
.highlight { color: blue; }
→ (0, 1, 0) = 10점 ❌
p.highlight { color: green; }
→ (0, 1, 1) = 11점 ❌
#title { color: red; }
→ (1, 0, 0) = 100점 ❌
#title.highlight { color: purple; }
→ (1, 1, 0) = 110점 ✅ 승자!
최종 결과: purple 색상이 적용됩니다! 🎉

💡 핵심 규칙

✅ 기억할 것
1. 명시도가 같으면 → 나중에 작성된 스타일이 적용
2. 왼쪽 숫자부터 비교 → (1, 0, 0)이 (0, 99, 99)보다 높음
3. 점수 개념: ID=100점, 클래스=10점, 태그=1점
4. 조합 선택자는 각 부분의 점수를 모두 더함
⚠️ 주의사항
!important 남용 금지: 유지보수가 매우 어려워집니다
인라인 스타일 지양: CSS 파일에서 관리하는 것이 좋습니다
과도한 ID 사용 자제: 클래스 선택자가 더 재사용성이 좋습니다
자식/자손 선택자 과용 금지: 불필요하게 명시도가 높아집니다

📚 추가 정보

특수한 경우들
상속된 스타일: 명시도 계산에 포함되지 않고, 가장 낮은 우선순위를 가집니다
:not() 가상 클래스: 자체는 점수가 없지만, 괄호 안의 선택자는 계산됩니다
:is(), :where(): :is()는 내부 선택자 점수 계산, :where()는 항상 0점
조합자(>, +, ~): 명시도 점수에 영향을 주지 않습니다
