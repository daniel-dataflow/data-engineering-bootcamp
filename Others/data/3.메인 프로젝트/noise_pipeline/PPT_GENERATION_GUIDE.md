# AI 프레젠테이션 생성 가이드 (Prompt)

이 문서는 Gamma, ChatGPT, SlidesAI 등의 AI 도구를 사용하여 "도시소음 개선 정보 제공 서비스" 프로젝트의 발표 자료를 만들기 위한 프롬프트입니다. 아래 내용을 복사하여 AI 도구에 입력하면 고품질의 초안을 얻을 수 있습니다.

---

## 🎭 AI 페르소나 및 목표
**역할**: 당신은 전문 데이터 엔지니어이자 솔루션 아키텍트입니다.
**목표**: 기술적인 데이터 파이프라인 프로젝트를 비전문가와 전문가 모두가 이해할 수 있도록 명확하고 매력적인 프레젠테이션으로 구성하는 것입니다.
**톤앤매너**: 전문적이고 신뢰감 있으면서도, 시각적으로 흥미로운 스타일.

---

## 📝 프로젝트 핵심 정보 (Context)

- **프로젝트명**: 도시소음 데이터를 활용한 소음 개선 정보 제공 서비스
- **핵심 기능**: 공공 데이터 수집 -> 실시간 처리 -> 분석 -> ML 예측 -> 시각화 대시보드
- **기술 스택**: Airflow, Kafka, PySpark, Scikit-learn, Streamlit, Docker
- **타겟 지역**: 서울특별시 강남구

---

## 📊 슬라이드 구성안 (Slide Outline)

아래 순서대로 총 10~12장의 슬라이드를 구성해 주세요.

### 슬라이드 1: 타이틀 (Title)
- **제목**: 도시의 소음을 데이터로 듣다
- **부제**: 공공 데이터를 활용한 실시간 소음 개선 정보 제공 서비스
- **발표자**: [이름 입력]
- **비주얼 아이디어**: 복잡한 도시의 빌딩 숲 위로 흐르는 데이터 스트림 이미지, 혹은 소음 파형이 데이터로 변환되는 세련된 그래픽.

### 슬라이드 2: 문제 제기 및 배경 (Problem & Background)
- **핵심 메시지**: "보이지 않는 소음, 어떻게 관리해야 할까요?"
- **내용**:
  - 도시화로 인한 소음 민원 급증
  - 기존 소음 관리의 한계 (실시간성 부족, 데이터 기반 의사결정 부재)
  - "데이터를 통해 소음을 눈으로 보고, 개선이 필요한 곳을 예측할 수 있다면?"

### 슬라이드 3: 솔루션 개요 (Solution Overview)
- **제목**: 데이터 기반 소음 관리 파이프라인
- **내용**:
  - **수집**: 공공 API에서 실시간 소음 데이터 확보
  - **분석**: PySpark로 대용량 데이터 집계 및 임계값 판정
  - **예측**: ML 모델로 신규 지역의 개선 필요성 예측
  - **결과**: Streamlit 대시보드를 통한 직관적 시각화

### 슬라이드 4: 전체 시스템 아키텍처 (System Architecture)
- **제목**: End-to-End 데이터 파이프라인
- **비주얼**: 왼쪽에서 오른쪽으로 흐르는 파이프라인 다이어그램
  1. **Source**: 공공 데이터 포털 API
  2. **Orchestration**: Apache Airflow (스케줄링)
  3. **Ingestion & Streaming**: Python fetcher -> Kafka (선택사항)
  4. **Processing**: PySpark (집계/분석)
  5. **Machine Learning**: Scikit-Learn (학습/예측)
  6. **Serving**: Streamlit (User Interface)

### 슬라이드 5: 핵심 기술 스택 (Tech Stack)
- **제목**: 견고하고 확장 가능한 기술 구조
- **내용**:
  - **Workflow**: Apache Airflow 3.0.6 (안정적인 태스크 관리)
  - **Analytics**: PySpark (대규모 데이터 처리 속도)
  - **Message**: Apache Kafka (실시간 데이터 처리 대비)
  - **ML/Web**: Scikit-learn & Streamlit (빠른 모델링 및 배포)
  - **Env**: Docker (재현 가능한 개발 환경)

### 슬라이드 6: 주요 기능 1 - 데이터 파이프라인 (Data Pipeline)
- **제목**: 매일 새벽 3시, 데이터는 멈추지 않는다
- **내용**:
  - Airflow DAG를 통한 완전 자동화
  - API 호출부터 DB 적재까지 사람의 개입 불필요
  - 장애 발생 시 자동 재시도(Retry) 메커니즘 

### 슬라이드 7: 주요 기능 2 - 분석 및 판정 로직 (Analysis Logic)
- **제목**: 소음 공해, 기준을 넘다
- **내용**:
  - **주간 기준**: 65dB 이상 소음 집중 지역 식별
  - **야간 기준**: 55dB 이상 정온 지역 감시
  - 측정소별 평균 데이터를 산출하여 '개선 필요 지역' 자동 태깅

### 슬라이드 8: 주요 기능 3 - ML 예측 모델 (ML Prediction)
- **제목**: 미지의 장소를 예측하다
- **내용**:
  - 측정되지 않은 위치라도 '위치 정보(위도/경도)'와 '예상 소음'으로 판정
  - 데이터 학습을 통해 개선 필요 여부(0/1) 이진 분류
  - 정책 입안 시 사전 시뮬레이션 용도로 활용 가능

### 슬라이드 9: 데모 / 사용자 경험 (User Experience)
- **제목**: 한눈에 보는 우리 동네 소음 지도
- **내용**:
  - 지도 위에 붉은 점(개선 필요)과 파란 점(양호)으로 시각화
  - 사이드바 필터로 원하는 조건만 즉시 검색
  - 복잡한 데이터가 아닌, 직관적인 인사이트 제공

### 슬라이드 10: 기대 효과 및 활용 방안 (Impact)
- **제목**: 데이터로 만드는 더 조용한 도시
- **내용**:
  - **행정**: 민원 발생 전 선제적 대응 및 유휴 예산 방지
  - **시민**: 거주지/방문지 소음 정보의 투명한 공개
  - **확장성**: 서울 강남구를 넘어 전국 도시로 확장 가능성

### 슬라이드 11: 마무리 (Closing)
- **제목**: Q&A
- **내용**: 감사합니다.
- **연락처**: [이메일/연락처 입력]
