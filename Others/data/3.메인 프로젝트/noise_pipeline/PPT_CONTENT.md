## 🎯 프로젝트 개요

### 프로젝트명
**도시소음 데이터를 활용한 소음 개선 정보 제공 서비스 개발**

### 프로젝트 설명
도시 소음 공공 데이터를 수집·분석하여 소음 현황을 시각화하고, 개선이 필요한 지역을 안내하며, 신규 위치의 소음 개선 필요 여부를 예측하는 데이터 파이프라인 서비스

### 타겟 지역
- 서울특별시 강남구

### 데이터 출처
- 공공 소음 정보 API: https://www.noiseinfo.or.kr/

## ⚙️ 주요 기능

### 1️⃣ 데이터 수집 (src/fetcher.py)
```
목표: 공공 소음 API에서 전국 소음 데이터 수집
프로세스:
  • NOISE_API_URL에서 POST 요청으로 데이터 조회
  • User-Agent 및 Referer 설정으로 API 접근
  • JSON 응답에서 'listEnMenu' 필드 추출
  • 타임아웃 10초 설정
```

### 2️⃣ 데이터 필터링 및 전처리 (src/processor.py)
```
목표: 강남구 데이터만 필터링 및 정규화
프로세스:
  • TARGET_REGION: "서울특별시 강남구"
  • 지역 기준 필터링
  • Pandas DataFrame으로 변환
  • CSV 저장 (data/raw/gangnam_noise_data.csv)
```

### 3️⃣ 실시간 스트리밍 (src/kafka_producer.py)
```
목표: 수집한 데이터를 Kafka로 실시간 전송
설정:
  • KAFKA_BOOTSTRAP_SERVERS: ["localhost:9092"]
  • KAFKA_TOPIC_RAW: "noise_raw_data"
  • Producer 설정으로 비동기 전송
```

### 4️⃣ PySpark 분석 (spark/noise_analysis.py)
```
목표: 대규모 데이터 집계 및 임계값 판정

처리 단계:
1. 측정소 단위로 주간/야간 평균 소음 계산
   - avg_day_noise: 주간 평균
   - avg_night_noise: 야간 평균

2. 임계값 기준으로 초과 여부 판정
   - DAY_THRESHOLD: 65 dB
   - NIGHT_THRESHOLD: 55 dB

3. 개선 필요도 산정
   - need_improvement: 주간 또는 야간 기준 초과 시 1

결과: data/processed/result.csv
```

### 5️⃣ ML 모델 학습 (src/ml.py)
```
목표: 위치와 소음 수준 기반 개선 필요 여부 예측

모델 특징:
  • 입력 특성: [avg_day_noise, avg_night_noise, wgs84Lat, wgs84Lon]
  • 타겟: need_improvement (0 또는 1)
  • 알고리즘: scikit-learn 분류 모델
  • 모델 저장: data/processed/model.pkl (pickle 형식)
```

### DAG 설정 (dags/noise_pipeline_dag.py)

```
DAG ID: noise_data_pipeline_ml
스케줄: 매일 03:00 UTC (0 3 * * *)
시작 일자: 2024년 1월 1일

작업 흐름:
fetch_and_send_noise_data (데이터 수집 및 Kafka 전송)
            │
            ▼

            │
            ▼
```

- **에러 처리**: 작업 실패 시 재시도 및 알림

## 🤖 분석 및 예측

### PySpark 기반 통계 분석

```
집계 단계:
┌─────────────────────────────────────────┐
│ 원본 데이터 (측정값별)                   │
│ - spotCode, spotName, spotAddr          │
│ - daytimeAve (주간 소음)                 │
│ - nightAve (야간 소음)                   │
│ - wgs84Lat, wgs84Lon (좌표)             │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│ 측정소 단위 집계 (GroupBy)               │
│ - 주간 소음 평균                         │
│ - 야간 소음 평균                         │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│ 판정 로직 적용                           │
│ - day_exceeded: avg_day > 65             │
│ - night_exceeded: avg_night > 55         │
│ - need_improvement: 둘 중 하나 초과      │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│ 최종 분석 결과 (CSV)                     │
│ - 측정소별 평균 소음                     │
│ - 개선 필요도 플래그                     │
└─────────────────────────────────────────┘
```

### ML 예측 모델

```
사용 사례: 신규 위치의 소음 개선 필요 여부 예측

입력 변수:
  • 주간 소음 수준 (dB)
  • 야간 소음 수준 (dB)
  • 위도 (wgs84Lat)
  • 경도 (wgs84Lon)

모델 출력:
  • 개선 필요 여부 (1: 필요, 0: 불필요)
  • 확률 점수 (신뢰도)

학습 데이터:
  • 강남구 측정소별 데이터
  • 피처: 4개 (소음 수준 + 좌표)
  • 타겟: 개선 필요도 (이진 분류)
```

#### 1. 사이드바 필터
```

```

#### 3. 지도 시각화
```
🗺️ 지도 표현:
├─ 빨간색 점: 기준 초과 지점 (개선 필요)
├─ 파란색 점: 기준 이하 지점 (양호)
└─ 입력된 위치 표시
```

#### 4. ML 위치 예측
```
🤖 예측 기능:
├─ 사용자 입력값:
│  ├─ 주간 소음 (0~150 dB)
│  ├─ 야간 소음 (0~150 dB)
│  ├─ 위도 / 경도
│  └─ 영향 반경
└─ 예측 결과 표시
```

#### 5. 상세 데이터
```
📋 테이블 표시:
├─ 측정소명
├─ 주소
├─ 평균 소음 (주간/야간)
└─ 개선 필요 여부
```
