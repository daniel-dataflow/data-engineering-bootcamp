4\. 모든 상품에 10~20달러 사이의 판매가격을 랜덤하게 만들어주고, item과 price 를 출력해보자



출력예시

\[

&nbsp; { item: 'canvas', price: 18 },

&nbsp; { item: 'journal', price: 17 },

&nbsp; { item: 'mat', price: 11 },

&nbsp; { item: 'mousepad', price: 18 },

&nbsp; { item: 'notebook', price: 10 },

&nbsp; { item: 'paper', price: 13 },

&nbsp; { item: 'planner', price: 13 },

&nbsp; { item: 'postcard', price: 14 },

&nbsp; { item: 'sketchbook', price: 15 },

&nbsp; { item: 'sketch pad', price: 18 }

]



4-1. 모든 상품을 판매했다고 예상했을때  총 판매대금은 얼마인가?



출력예시

\[ { \_id: null, totalSales: 10805 } ]

출력 예시

\[

  { item: 'mousepad', itemLength: 8 },

  { item: 'notebook', itemLength: 8 },

  { item: 'postcard', itemLength: 8 },

  { item: 'sketchbook', itemLength: 10 },

  { item: 'sketch pad', itemLength: 10 }

]

\[
